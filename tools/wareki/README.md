# wareki — 和暦の日付を、改元の日を境界とする 1 つの表で西暦に直す

帳票や CSV に混ざる和暦(令和 6 年 / R6.4.1 / 平成元年 / 全角数字)を正規表現の寄せ集めで読むと、
改元をまたぐ日付(平成 31 年 5 月 1 日、昭和 64 年 1 月 8 日)が「年の足し算」で黙って通る。
この道具は元号ごとの開始日と終了日を 1 つの表(`ERAS`)に持ち、表の外の日付は例外で止まる。
逆変換(西暦 → 和暦)も同じ表から引く。改元日当日は新元号。stdlib のみ(datetime / re / unicodedata)、依存なし。

## 改元表(これが唯一の正本)

| 元号 | 略字 | 元年 | 開始日 | 終了日 |
|---|---|---|---|---|
| 明治 | M | 1868 | 1873-01-01(太陽暦の採用日。それより前は変換しない) | 1912-07-29 |
| 大正 | T | 1912 | 1912-07-30 | 1926-12-24 |
| 昭和 | S | 1926 | 1926-12-25 | 1989-01-07 |
| 平成 | H | 1989 | 1989-01-08 | 2019-04-30 |
| 令和 | R | 2019 | 2019-05-01 | (続く) |

## 変換の流れ(固定)

| 段 | すること | 止まる条件 |
|---|---|---|
| 1 | 表記の正規化(NFKC で全角 → 半角、空白除去、元年 → 1 年) | — |
| 2 | 元号の解決(漢字 / 一字 / 略字 → 表の行) | 解釈できない表記 |
| 3 | `date` を作る | 存在しない日(2 月 30 日、13 月) |
| 4 | 改元表で照合(開始日 <= 日付 <= 終了日) | 改元後の旧元号 / 改元前の新元号 / 太陽暦以前 |

`strict=False`(CLI は `--lenient`)は「終了日を過ぎた旧元号」(平成 32 年 4 月 1 日 → 2020-04-01)だけを読み替える。
改元前の日付に新元号を付けたもの(大正元年 1 月 1 日)と存在しない日は、strict に関わらず止まる。

## 使い方

```
python wareki.py 令和6年4月1日 R6.4.1 Ｒ６．４．１   # 1 行 1 件で ISO 日付(2024-04-01)。exit 0
python wareki.py 平成31年5月1日                      # NG: 平成は 2019-04-30 で終わっている … exit 3
python wareki.py --lenient 平成31年5月1日            # 2019-05-01
python wareki.py --reverse 2019-05-01                # 令和元年5月1日
type dates.txt | python wareki.py -                  # 標準入力の各行を「入力 TAB 結果」で出力。1 件でも止まれば exit 3
```

```python
from wareki import to_date, parse_date, to_wareki, WarekiError

to_date("令和6年4月1日")            # datetime.date(2024, 4, 1)
parse_date("2024/4/1")             # 和暦と西暦が同じ列に混ざるとき。4 桁で始まれば西暦
to_wareki(date(2019, 5, 1))        # '令和元年5月1日'(改元日当日は新元号)
to_wareki(date(2019, 5, 1), style="letter")   # 'R1.5.1'
```

受け付ける表記: `令和6年4月1日` / `令和 6 年 4 月 1 日` / `令6.4.1` / `R6.4.1` / `r6/4/1` / `R06-04-01` /
`令和６年４月１日` / `Ｒ６．４．１` / `令和元年5月1日`。

## テスト

```
python -m pytest tools/wareki -q      # fixture は全て合成データ(fixtures/make_fixtures.py で再生成可)
```

`tests/test_wareki.py` の `test_measure_*` が、「正規表現 + 年の足し算」だけの素朴な変換とこの道具を
合成 1,000 件(固定 seed)で比べている。記事に載せる数値はそこから取り、`assert 変数 == 値` で固定してある。

## できないこと

- 明治 6 年 1 月 1 日(1873-01-01)より前は変換しない(止まる)。それ以前は太陰太陽暦で、年の足し算では日付が対応しない
- 元号コード(1 = 明治 … 5 = 令和 のような番号)や、明治より前の元号は表に無い。必要なら `ERAS` に足してテストを追加する
- 「平成 32 年」のような改元後の旧元号は、既定では止まる。読み替えたいときは明示的に `strict=False` / `--lenient` を付ける
- 年だけ・年月だけの表記(令和 6 年、令和 6 年 4 月)は読まない。日まで揃った表記だけを扱う
- 時刻は扱わない
