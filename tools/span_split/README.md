# span_split — 料率が変わる日が期間の途中に来るので、期間を先に境界で切ってから行を当てる

**値が切り替わる日が期間の途中に来るとき、期間を 1 つのまま 1 本の日付で引くと、片側の値が
黙って期間全体に当たる。** [asof_table](../asof_table) の回で、行の側に基準日・公表時点・
対象・順位の列を足して「1 点の日付で引く」ところは決まるようにした。けれど引く単位が
**点ではなく期間** のとき(在籍期間、賃金計算期間、給付の支給期間、契約期間)は、その期間の
どこかに境界日が来ると、どの行を当てるかが 1 つに決まらない。

この部品は、切る日を **境界表からだけ** 取り、期間を小期間に割って、小期間ごとに行を 1 つ当て、
期間ごとに 4 値(**境界で切れた / 境界に当たらず 1 本のまま / 当たる行が決まらない /
止まった**)に分ける。

持たせていないものが規律になっている。

- **境界表に無い日で切らない**(規定の自然文や行の表の有効開始日から境界を推測して足す経路が
  無い。[variant_fan](../variant_fan) の「軸を推測して足さない」/
  [order_table](../order_table) の「鍵を推測して足さない」を継いでいる)
- **当日の帰属が空欄の境界行は切らずに止まる**(境界日当日を新側に寄せる既定を持たない。
  [wareki](../wareki) の「改元日当日は新元号」が表の宣言として在るから通る、という形を
  そのまま入力の形にした)
- **境界日が決まっていない行(施行日が政令待ち)は、知識として読み込むが切るのには使わず、
  理由コードで止まる**(未定を今日の日付や公表日で埋めない)
- **公表時点が期間より後の境界は、宣言された扱いで切るか切らないかを分け、どちらに寄せたかを
  必ず欄に残す**(黙ってどちらかに寄せない。[asof_table](../asof_table) の公表時点の列と対)
- **金額を触らない**(按分・日割り・丸めの引数が無い。返すのは小期間の開始日・終了日・日数と
  当たった行まで。分母を 30 にするか 31 にするかは [variant_fan](../variant_fan) が数えた軸の
  領域で、この部品の外)
- **小期間の日数の合計が元の期間の日数と一致しない結果を返さない**(切り落ちと重複を自分で
  検算して、合わなければ止まる)
- **同じ日に 2 行当たったら宣言された段階の順と行の順位で決め、どちらも空なら止まる**
  (表の並び順で静かに勝たせない。[asof_table](../asof_table) の順位の列と同じ規律)
- **切れた期間の率を単独で返さない**(小期間の件数・境界で切れた期間の件数・止まった件数と
  分母の内訳を併記。[check_census](../check_census) /
  [scope_ledger](../scope_ledger) 以降と同じ)
- **入力表を書き換えず、境界行も期間行も生成しない**([intake_triage](../intake_triage)
  以降と同じ)
- **出典の欄が空の境界行・行の表の行は使わずに止まる**([source_pin](../source_pin) /
  [reader_registry](../reader_registry) と同じ)
- **float を使わない**(日数は date の差の整数、値は文字列のまま運ぶ)
- **「当たる行が決まらない」と「止まった」を混ぜない**([answer_check](../answer_check) /
  [check_census](../check_census) / [env_match](../env_match) と同じ 4 値の規律)

## 入力 — 期間表と境界表と行の表の 3 つ

期間表は 4 列。期間は **終わりの日を含む閉じた期間** として読む。

| 列 | 意味 |
|---|---|
| `target` | 対象(空欄は「表として読めない」) |
| `start` | 開始日(ISO) |
| `end` | 終了日(ISO、この日を含む) |
| `basis` | 基準日の種別。登録の 6 種別(`対象月初日` / `賃金締切日` / `労働日` / `資格取得日` / `請求日` / `離職日`)の外は**止まる** |

境界表は 8 列で、業種の語彙を 1 つも持たない。

| 列 | 意味 |
|---|---|
| `boundary` | 境界日(ISO)。空欄か `未定` は、知識として読むが切るのには使わず**止まる** |
| `moved` | 動いたもの(空欄は「表として読めない」) |
| `onday` | 当日の帰属。`新側` / `旧側`。**空欄は止まる** |
| `step` | 段階の順(整数か空欄) |
| `known_from` | 公表時点(ISO か空欄) |
| `known_use` | 公表時点が期間より後だったときの扱い。`切る` / `切らない`。公表時点が在って空欄なら**止まる**(公表時点が空の行に書くと「表として読めない」) |
| `source` | その行の出典(ファイル名 + 行番号 or URL)。**空欄は止まる** |
| `swap` | 入れ替え方。`verify` が境界表の行順を入れ替えるときの宣言 |

```csv
boundary,moved,onday,step,known_from,known_use,source,swap
2020-09-01,標準報酬月額等級表_厚年の上限,新側,,,,日本年金機構 / 私の棚卸し記録(非公開),逆順
2023-04-01,割増賃金率の猶予終了,新側,,,,厚生労働省 / 私の棚卸し記録(非公開),
2025-04-01,高年齢雇用継続給付の支給率,新側,,,,articles/02_wareki.md L13,
```

行の表は 6 列で、[asof_table](../asof_table) の回と同じ形になっている。

| 列 | 意味 |
|---|---|
| `value` | 値(文字列のまま運ぶ) |
| `valid_from` | 有効開始日(ISO) |
| `known_from` | 公表時点(ISO か空欄)。**この部品は引く時点で絞らない**(出典と並べて返すだけ) |
| `target` | 対象。空欄はどの対象にも当たる |
| `priority` | 順位(整数か空欄)。0 が本則、10 が経過措置 |
| `source` | 出典。**空欄は止まる** |

## 当日の帰属 — 1 欄で切れ目が 1 日動く

境界日そのものがどちら側に入るかは、**表の宣言から取る**。

| 当日の帰属 | 切れ目 | 2025-01-01〜2025-06-30 を 2025-04-01 で切ると |
|---|---|---|
| `新側` | 境界日が新しい小期間の初日 | 90 日(〜03-31)+ 91 日(04-01〜) |
| `旧側` | 境界日が古い小期間の最終日 | 91 日(〜04-01)+ 90 日(04-02〜) |

既定は持たせていない。空欄の境界行が 1 行でもあれば、1 本も切らずに止まる。

## 4 値 — 「決まらない」と「止まった」を混ぜない

| 値 | いつ入るか |
|---|---|
| `境界で切れた` | 期間の内側に切れ目があり、小期間すべてに行が 1 つ当たった |
| `境界に当たらず 1 本のまま` | 期間の内側に切れ目が無く、その 1 本に行が 1 つ当たった |
| `当たる行が決まらない` | どれかの小期間で、当たる行が 0 件か 2 行以上だった |
| `止まった` | 理由コードが返った期間(開始日 > 終了日、基準日の種別が未登録 など) |

`当たる行が決まらない` は理由コードではない。切る手続きは成立しているので、どの小期間で
決まらなかったかが返る(終了コードは 3)。

## いつも成り立つこと

切った結果は 2 通りしかない。

- 小期間の日数の合計が元の期間の日数と一致し(切り落ちも重複も 0)、小期間は隙間なく連続し、
  小期間の開始日は元の期間の開始日か **境界表に宣言された切れ目の日だけ** で、4 値の合計が
  切った期間の本数に等しく、判定部分に時刻・ホスト名・絶対パスが 1 つも入らず、**境界表の
  行順を入れ替えても同じバイト列** になる
- または、1 本も結果を返さずに理由コードが返る(結果や指紋を取りに行くと例外になる)

どちらの場合も、この部品は期間表も境界表も行の表も 1 文字も書き換えない。

この 1 文を `tests/test_span_split_property.py` の `@given` テストが確かめている(期間を
1〜3 本、境界を 1〜3 行、行を 1〜3 行、当日の帰属と段階の順と公表時点とその扱いを乱数で振り、
3 割くらいの確率でどこか 1 か所を崩す。乱数は固定で毎回同じ 150 通り)。**期待する切れ目は
部品の split を呼ばず、境界日と当日の帰属から date の足し算で直に出すテスト側の別実装で
計算している。** 同じファイルの 2 本目は 300 通りで「境界日が期間の内側にあるかぎり、当日の
帰属を `旧側` にすると前の小期間が 1 日増え、後の小期間が 1 日減る」ことを見ている。

## 出力 — 切れた率は単独では返らない

`check` と `split` が返すのは、期間表の行数・境界表の行数・境界日が未定の行数・行の表の行数・
4 値の件数・小期間の件数・境界で切れた期間の件数・止まった期間の件数・行が当たった小期間の
件数・公表時点が期間より後だった境界の件数、それに分母の内訳と 3 つの固定行だ。**率だけを
返す呼び方も、option も無い。**

```
"4 値": {"境界で切れた": 4, "境界に当たらず 1 本のまま": 1,
         "当たる行が決まらない": 0, "止まった": 0},
"小期間の件数": 9, "行が当たった小期間の件数": 9, "境界日が未定の行数": 0
```

固定行は 3 つとも消せない。「境界は宣言された日だけ」(推測して足す経路が無いこと)、
「日数の検算」(合計が合わない結果は返さないこと)、「金額は触らない」(按分・日割り・丸めが
無いこと)だ。`split` はさらに期間ごとの内訳(小期間の開始日・終了日・日数・開いた境界・
段階の順・当たり方・値・有効開始日・順位・公表時点・出典・行番号)と、公表時点が期間より後
だった境界をどちらに寄せたかを出す。

`verify` は 3 つ見る。2 回切って判定部分のバイト列の sha256 を突き合わせること、**宣言された
入れ替え方で境界表の行順を入れ替えても同じ出力になるか**、そして **小期間の日数の合計が元の
期間の日数と一致するか** だ。一致しなければ観測としてそのまま返す。

## 止まる理由コード(12 個)

```
境界表が 0 行 / 当日の帰属が空 / 境界日が未定 / 公表時点の扱いが宣言されていない /
出典の欄が空 / 基準日の種別が未登録 / 同じ日に同じ動いたものが 2 行 /
段階の順と順位がどちらも空 / 開始日 > 終了日 / 日数の合計が元の期間と合わない /
2 回目の判定部分が不一致 / 境界表の行順を入れ替えた表で出力が変わる
```

`開始日 > 終了日` は「期間が 0 日」も兼ねている(終わりの日を含む閉じた期間なので、
0 日になるのは開始日が終了日より後のときだけ)。

次のものは理由コードにせず、**「表として読めない」として終了コード 2 で返す**。当日の帰属・
公表時点の扱い・入れ替え方が登録の外の語だったとき、列そのものが足りないとき、公表時点が空の
行に扱いを書いたとき、入れ替え方の宣言が 2 通りあるとき、動いたもの・対象・基準日の種別・値が
空欄のとき、日付が ISO として読めないとき(和暦は [wareki](../wareki) の仕事)、段階の順・
順位が整数として読めないとき、期間表や行の表が 0 行のとき。

## 使い方

```bash
python span_split.py init ひな型/                       # 3 枚の表のひな型を書く
python span_split.py check  期間表.csv 境界表.csv 行の表.csv   # 件数と分母の内訳
python span_split.py split  期間表.csv 境界表.csv 行の表.csv   # 上 + 期間ごとの内訳と指紋
python span_split.py verify 期間表.csv 境界表.csv 行の表.csv   # 2 回 + 行順入れ替え + 日数の検算
```

終了コードは、**小期間すべてに行が 1 つ当たったときだけ 0**、決まらない行があるときや止まった
ときは 3、表として読めなければ 2。まとめて走らせる仕組みの中に置いて、3 で止められる。

関数としても同じ形で呼べる。

```python
from span_split import Spans, Boundaries, Rows, split

m = split(Spans.load("期間表.csv"), Boundaries.load("境界表.csv"), Rows.load("行の表.csv"))
print(m.counts() if m.report.ok else [p.reason for p in m.report.pending])
```

CLI は `split` / `check` / `verify` / `init` の 4 つで、option は `-h` 以外に 1 つも無い。
そのこともテストで固定してある。

## テストと fixture

```bash
python -m pytest tools/span_split -q      # 54 passed(2026-10-14 実走)
```

`fixtures/` に期間表 3 枚・境界表 7 枚・行の表 3 枚と、崩した表 23 枚が入っている。
**値・対象・期間は全て架空で、実在の金額や率や取引先名は 1 つも入れていない。** 境界日と
動いたものの名前だけは、私の棚卸し記録(非公開)に出典つきで並んでいる実在の改定を写した
(日付と動かした主体は公表されている情報)。出典のうち 6 件はこの repo 内の実在の行
(`articles/02_wareki.md` L13・L40 / `articles/07_asof_table.md` L15・L45・L46 /
`articles/19_variant_fan.md` L32)を指し、テストがその行を開いて語が在ることまで確かめて
いる。`fixtures/make_fixtures.py` を実行すると、崩した表ごと書き直す。

## できないこと

- 判定したことは「宣言された境界日で期間が切れるか、小期間ごとに当たる行が 1 つに決まるか」
  までで、**どの切り方が制度として正しいかは判定しない**
- **金額を出さない。** 小期間の日数までで止まるので、按分の分母をどう取るかも、端数をどちらに
  寄せるかも、この部品の外になる
- **境界表が足りているかも判定しない。** 書かれていない改定は無いものとして扱われるので、
  境界を拾ってくるのは人の側になる
- **なぜ施行日が決まっていないかも言わない。** 未定の行は未定のまま置いて止まるだけで、
  見込みの日付を埋める経路が無い
- 対象の指定は空欄(どの対象にも当たる)と完全一致だけで、帯や階層の照合はしない
- 同じ日に 2 行当たったときに、細かい対象の行を自動で優先することはしない。優先は順位の列に
  書く(書かれていなければ止まる)
- 期間は閉じた期間として読む。半開区間の表を渡すと終わりの日が 1 日ずれるので、渡す前に
  揃えるのは人の側になる
- 上の件数は、合成した表に対する測定で、他の人の環境で同じ数字になるとは限らない
