# regen_axis — ファイルの一覧を、書き手と作り直す元の軸で並べ直す

解説記事: [役割の一覧に並んだファイルも失って戻せるかは別なので、誰が書くかと作り直す元の軸で並べ直す](https://chronicles-of-solo-parenting.blogspot.com/2026/11/blog-post_11.html)(2026-11-12 公開)
<!-- article-links:end -->

フォルダの中身を「役割」で並べた一覧は、何のためのファイルかは答えるが、そのファイルを誰が書き、
何から作り直せるかは答えない。この部品は、同じ一覧を**書き手**と**作り直す元**の軸で並べ直す。
人が書いたきりのもの・実行のたびに書き換わるもの・外から取ってきた写し・前回の控え・どれにも当たらないものが、
別の段に分かれる。

**読むのは渡された 5 枚の表だけ。** ディスクを歩かない、ファイルの中身や更新時刻を読まない、消さない、
動かさない、走らせない。**消してよいかは決めない。** 名前や拡張子から書き手を当てない。
標準ライブラリのみ(csv / json / hashlib / argparse)、依存なし。

## 入力の 5 枚(どの行にも出典の欄が要る)

| 表 | 列 |
|---|---|
| ファイルの台帳 | file id / 名前 / 置き場 / 役割 / 書き手の記号 / 取り先 / 出典 |
| 書き手の登録表 | 記号 / 意味 / 出典 |
| 作る線の台帳 | 線 id / 入力の file id / 出力の file id / 出典(1 行 = 入力 1 つと出力 1 つ) |
| 言い方の台帳 | 言い方 id / file id / 文言 / 出典 |
| 一覧の台帳 | 一覧 id / file id / 出典(どの一覧にそのファイルが載っているか) |

名前と役割は渡された文字をそのまま写す(判定に使わない)。書き手の記号は `人が書く` / `実行が書く` /
`外から取る` / `控え` と、登録表に在るその他の記号。空欄は `書き手の記載なし` になる。
出典が空の行は、ファイルの台帳なら別枠に出し、ほかの 4 枚なら使わずに「使わなかった行」に理由つきで返す。

## 区分(ファイル 1 件に 1 つ)

| 区分 | 条件 |
|---|---|
| (A) 人が書き、どの線の出力にも出ない | 記号が `人が書く` で、出力として出る線が無い |
| (B) 実行が書き、出力として出る線が在る | 記号が `実行が書く` で、出力として出る線が 1 本以上在る |
| (C) 外から取り、取り先の記載が在る | 記号が `外から取る` で、取り先が書いてある |
| (D) 控え | 記号が `控え` |
| (E) A〜D に当たらない | 内訳 3 つ = どの線にも出ない / 入力にだけ出る / 出力に出るが書き手が実行でない |

別枠の理由は 6 つで、手前が勝つ: file id が重複 / 出典が空 / 書き手の記号が登録表に無い /
外から取るのに取り先が空 / 線の端が台帳に無い / 線が輪になる。

ほかに返すもの: ファイルごとの「作り直す元」(その線の入力)と「遡った端」(線を上へ辿った先)、
置き場ごとの書き手の種類(2 種類以上なら `書き手が混ざる` の印だけ)、同じファイルに 2 行以上在る言い方
(並べるだけ)、片方の一覧にしか載らないファイル(理由は言い当てない)。

## いつも成り立つこと

ファイルの台帳の 1 行には、区分 5 つか別枠の理由 6 つのうち 1 つだけが付き、その合計は台帳の行数に等しく、表の行順を入れ替えても答えは変わらず、渡した表は 1 文字も書き換わらない。

この 1 文は `tests/test_regen_axis_property.py` が性質テスト(hypothesis)で確かめている。台帳・登録表・線を
乱数で作り(file id の重複、空の出典、登録に無い記号、台帳に無い端、輪を含む)、区分はテストの中で別の書き方で
引き直して比べる(道具の判定は呼ばない)。乱数は固定で、毎回同じ 300 通り。

## 使い方

```
python regen_axis.py check  files.csv writers.csv lines.csv sayings.csv lists.csv
python regen_axis.py rows   files.csv writers.csv lines.csv sayings.csv lists.csv   # ファイル 1 件 1 行の CSV
python regen_axis.py verify files.csv writers.csv lines.csv sayings.csv lists.csv   # 5 つの検算
```

終了コードは 0 = 判定した / 3 = verify のどれかが合わない / 2 = 表の形の誤り(1 件も判定しない)。

`verify` が見る 5 つ: 二度走って同じ指紋(sha256)か / 5 枚の行順を入れ替えても同じ出力か /
区分 + 別枠 = ファイルの件数か / 線を 1 行外すと、その線の出力のファイル(と、同じ輪の上に居たファイル)だけ
区分が動くか / 書き手の記号を 1 行だけ `実行が書く` から `人が書く` に替えると、そのファイルと同じ置き場の印だけが
変わるか。写しはメモリの中だけで作る。

```python
import regen_axis as R
tables = R.read_all(["files.csv", "writers.csv", "lines.csv", "sayings.csv", "lists.csv"])
result = R.judge(tables)          # 区分 / 別枠 / ファイルごと / 置き場ごと / 言い方 / 一覧
```

## テストと入力例

```
python -m pytest tools/regen_axis -q        # 28 passed
python fixtures/make_fixtures.py            # 入力例を作り直す
```

- `fixtures/gousei/` は全て架空の 24 行で、5 つの区分・E の内訳 3 つ・別枠 6 つの理由がすべて出る
- `examples/futatsu_no_ichiran/` は、同じフォルダについて書かれた 2 枚の一覧を写した 27 行。書き手の記号は、
  一覧のどこかに根拠の文が在る行にだけ書き、無い行は空欄のままにしてある。試験では最後の 1 本でだけ通す

## できないこと

- 消してよいかを決めない。消してよいかの列も、危なさの点数も、順位も持たない
- フォルダの実物を見ない。台帳に書いていないファイルは存在しないのと同じに扱う
- 書き手の記号が正しいかは確かめない。宣言された記号を登録表に当てるだけ
- 作り直せることを確かめない。分かるのは「作り直す線の記載が在るか」までで、実際に消して走らせてはいない
- 外から取る写しが、いまも取り先から取れるかは見ない(取りに行かない)
- 同じファイルへの言い方が 2 通り在っても、どちらが正しいとも言わない
- 片方の一覧にしか載らない理由は言い当てない
