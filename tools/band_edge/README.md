# band_edge — 帯の境界ちょうどの値はどちらにも入るので、以上と未満を表に書いてから引く

**帯の境界ちょうどの値は、以上と未満のどちらを書いたかが表に無いと、どちらの帯にも入れられる
(そして黙ってどちらかに入る)。** [asof_table](../asof_table) の回で「1 点の日付で行を引く」、
[span_split](../span_split) の回で「期間を境界日で切って行を当てる」ところまでは決まるように
した。けれど行が当たった後に **値を帯に当てる** 段(月額から段へ、日数から率へ、年数から
日数へ)では、境界値そのものと等号の向きが宣言されていないと、当たる帯が 1 つに決まらない。

この部品は、等号の向きを **帯の表の欄からだけ** 取り、値を帯に当て、値の行ごとに 4 値
(**帯が 1 つに決まった / 当たる帯が無い / 決まらない(重なり)/ 止まった**)に分ける。
境界値ちょうどに触れた行は、別の欄で数えて返す。

持たせていないものが規律になっている。

- **等号の欄が空の帯行は使わずに止まる**(「以上・未満」を既定にしない。この部品の骨を
  そのまま入力の形にしたところ)
- **上端・下端が開いている帯は、宣言で「開いている」と書かれた時だけ許す**(空欄と開放を
  区別し、空欄を無限と読み替えない)
- **帯の重なりと隙間を自分で検算し、合わなければ止まる**(宣言された範囲を帯の連結が覆うか。
  [span_split](../span_split) が小期間の日数を自分で突き合わせたのと同じ形)
- **値を帯に入れるために丸めない・寄せない**(四捨五入・切上げ・切捨ての引数が無い。丸めは
  [formula_table](../formula_table) が「隣の列に書く」とした領域で、こちらは触らない)
- **単位が違う値を黙って換算しない**(時間と分、円と千円は、換算の宣言が無ければ止まる)
- **境界ちょうどに当たった件数を必ず別の欄で数えて出す**(下限ちょうど / 上限ちょうど /
  その両方。当たった率を単独で返さず分母の内訳を併記。[check_census](../check_census) 以降と
  同じ)
- **当たる帯が 2 つなら「決まらない(重なり)」、0 なら「当たる帯が無い」として返す**
  (最寄りの帯に寄せる経路が無い、端の帯に押し込まない)
- **等号の向きを総当たりで並べない**(以上と超を両方試して答えが 2 通り出ることを示す経路は
  持たない。それは [variant_fan](../variant_fan) の数える側の仕事で、この部品は宣言が 1 つに
  決まらなければ止まる側)
- **日付で帯の表の版を選ばない**(基準日・公表時点の引数が無い。版を選ぶのは
  [asof_table](../asof_table)、期間を切るのは [span_split](../span_split) の仕事)
- **帯の行も値の行も生成せず、入力表を書き換えない**([intake_triage](../intake_triage)
  以降と同じ)
- **出典の欄が空の帯行・値の行は使わずに止まる**([source_pin](../source_pin) /
  [reader_registry](../reader_registry) と同じ)
- **float を使わない**(値は Decimal、日数・年数は整数、比較は宣言された値の種類でのみ行い
  文字列比較に落とさない)

## 入力 — 値の表と帯の表と単位の宣言の 3 つ

値の表は 6 列。

| 列 | 意味 |
|---|---|
| `target` | 対象(空欄は「表として読めない」) |
| `item` | 項目。単位の宣言に無い項目は**止まる** |
| `value` | 値(Decimal。指数表記は受けない) |
| `kind` | 値の種別。登録の 6 種(`金額` / `日数` / `月数` / `年数` / `時間` / `人数`)。**空欄は止まる** |
| `unit` | 単位。項目の宣言と違うときは換算の宣言が要る |
| `source` | その行の出典。**空欄は止まる** |

帯の表は 9 列で、業種の語彙を 1 つも持たない。

| 列 | 意味 |
|---|---|
| `item` | 項目 |
| `no` | 帯の番号(整数。同じ項目で重複したら**止まる**) |
| `low` | 下限(数 か `開いている`)。**空欄は止まる**(空欄を無限と読み替えない) |
| `low_eq` | 下限の等号。`以上` / `超`。下限が数のときに**空欄なら止まる** |
| `high` | 上限(数 か `開いている`)。**空欄は止まる** |
| `high_eq` | 上限の等号。`未満` / `以下`。上限が数のときに**空欄なら止まる** |
| `returns` | 当たったときに返すもの(空欄は「表として読めない」) |
| `source` | その行の出典。**空欄は止まる** |
| `swap` | 入れ替え方。`verify` が帯の表の行順を入れ替えるときの宣言 |

```csv
item,no,low,low_eq,high,high_eq,returns,source,swap
合成の月額(架空),1,開いている,,100000,未満,合成の段1(架空),協会けんぽ / 私の棚卸し記録(非公開),逆順
合成の月額(架空),2,100000,以上,200000,未満,合成の段2(架空),協会けんぽ / 私の棚卸し記録(非公開),
合成の月額(架空),3,200000,以上,開いている,,合成の段3(架空),協会けんぽ / 私の棚卸し記録(非公開),
```

単位の宣言は 6 列。

| 列 | 意味 |
|---|---|
| `item` | 項目(2 行書くと「表として読めない」) |
| `kind` | 値の種別。登録の 6 種 |
| `unit` | この項目を引くときの単位 |
| `digits` | 小数の桁。`日数` / `月数` / `年数` / `人数` は 0 だけ |
| `from_unit` | 換算の相手(空欄 = 換算を宣言していない) |
| `factor` | 係数(`from_unit` の値に掛けると `unit` になる) |

## 等号の 1 欄 — 同じ値が 1 つに決まったり決まらなくなったりする

境界値そのものがどちらの帯に入るかは、**表の宣言から取る**。

| 帯 1 の上限 | 帯 2 の下限 | 100000 はどこに入るか |
|---|---|---|
| `100000 未満` | `100000 以上` | 帯 2 だけ(1 つに決まる) |
| `100000 以下` | `100000 以上` | 帯 1 と帯 2 の両方(**決まらない(重なり)**) |
| `100000 以下` | `100000 超` | 帯 1 だけ(1 つに決まる。返すものが隣に動く) |

既定は持たせていない。等号の欄が空の帯行が 1 行でもあれば、1 行も引かずに止まる。

## 4 値 — 「当たらない」と「決まらない」と「止まった」を混ぜない

| 値 | いつ入るか |
|---|---|
| `帯が 1 つに決まった` | 宣言された等号で、値を含む帯がちょうど 1 つだった |
| `当たる帯が無い` | 値を含む帯が 0 件だった(最寄りの帯にも端の帯にも寄せない) |
| `決まらない(重なり)` | 値を含む帯が 2 つ以上だった(どちらかを選んで返さない) |
| `止まった` | 理由コードが返った項目の行(等号が空、帯の隙間 など) |

`当たる帯が無い` と `決まらない(重なり)` は理由コードではない。引く手続きは成立している
ので、どの行がそうなったかが返る(終了コードは 3)。

## 覆いの検算 — 帯の連結を、値を 1 つも見る前に突き合わせる

項目ごとに、両端の閉じた帯を並べ、隣り合う帯の等号から次の 3 つに分ける。

- **隙間**(次の帯の下限が、前の帯の上限より 2 刻み以上あいている)→ **止まる**
- **点の重なり**(境界値ちょうど 1 つだけが 2 つの帯に入る)→ 止めずに、その値の行を
  `決まらない(重なり)` で返す。この部品の主題はここなので、表の不備ではなく結果として出す
- **範囲の重なり**(2 刻み以上が重なっている)→ **止まる**

そのうえで、帯の連結の幅(刻みの個数)と、帯ごとの個数の合計から点の重なりを引いた数を
突き合わせる。合わなければ `覆いの検算が合わない` で止まる。幅と個数は別の関数で数えて
いるので、数え方を片方だけ差し替えると、この検算が自分で見つけて止まる。

## いつも成り立つこと

引いた結果は 2 通りしかない。

- 値の行ごとに 4 値が 1 つだけ付き、4 値の合計が引いた行数に等しく、当たった帯は **宣言された
  等号で値を含む帯だけ** で、境界ちょうどの件数が宣言された境界値と一致した行数に等しく、
  判定部分に時刻・ホスト名・絶対パスが 1 つも入らず、**帯の表の行順を入れ替えても同じ
  バイト列** になる
- または、1 行も「帯が 1 つに決まった」を返さずに理由コードが返る(結果や指紋を取りに行くと
  例外になる)

どちらの場合も、この部品は値の表も帯の表も単位の宣言も 1 文字も書き換えない。

この 1 文を `tests/test_band_edge_property.py` の `@given` テストが確かめている(帯を 1〜3 本、
値を 1〜3 行、等号の向きを乱数で振り、3 割くらいの確率でどこか 1 か所を崩す。乱数は固定で
毎回同じ 150 通り)。**当たる帯は部品の `holds` を呼ばず、宣言された等号から Decimal の
大小比較で直に出すテスト側の別実装で計算している。** 同じファイルの 2 本目は 300 通りで、
「上限の等号を `未満` から `以下` に変えると、境界値ちょうどの行だけが
`決まらない(重なり)` に変わり、ほかの値の行は変わらない」ことを見ている。

## 出力 — 当たった率は単独では返らない

`check` と `match` が返すのは、値の表の行数・帯の表の行数・単位の宣言の行数・項目の数・
4 値の件数・境界ちょうどの件数(下限ちょうど / 上限ちょうど / 両方に触れた)・換算した値の
行数・点の重なりの件数、それに分母の内訳と 3 つの固定行だ。**率だけを返す呼び方も、option も
無い。**

```
"4 値": {"帯が 1 つに決まった": 12, "当たる帯が無い": 1,
         "決まらない(重なり)": 0, "止まった": 0},
"境界ちょうど": {"下限ちょうど": 7, "上限ちょうど": 7, "両方に触れた": 6},
"換算した値の行数": 1, "点の重なり": 0
```

固定行は 3 つとも消せない。「等号は宣言された欄だけ」(以上・未満を補う既定が無いこと)、
「覆いの検算」(幅と個数の突き合わせ)、「丸めない・寄せない」(四捨五入も最寄りの帯への
寄せも無いこと)だ。`match` はさらに値の行ごとの内訳(引いた値・換算・当たった帯・返すもの・
下限ちょうど・上限ちょうど・出典・行番号)と、境界ちょうどに触れた行だけを並べた表を出す。

`verify` は 3 つ見る。2 回引いて判定部分のバイト列の sha256 を突き合わせること、**宣言された
入れ替え方で帯の表の行順を入れ替えても同じ出力になるか**、そして **帯の連結が宣言された範囲を
隙間なく覆っているか** だ。合わなければ観測としてそのまま返す。

## 止まる理由コード(13 個)

```
等号が空 / 開放の宣言が無い空欄 / 帯の重なり / 帯の隙間 /
単位の宣言が無いか換算が未宣言 / 出典の欄が空 / 値の種類が空 / 下限 > 上限 /
帯の番号の重複 / 該当項目の帯が 0 件 / 覆いの検算が合わない /
2 回目の判定部分が不一致 / 行順を入れ替えた表で出力が変わる
```

次のものは理由コードにせず、**「表として読めない」として終了コード 2 で返す**。等号・値の
種別・入れ替え方が登録の外の語だったとき、開いている端に等号を書いたとき、列そのものが
足りないとき、帯の番号・返すもの・対象・項目・単位が空欄のとき、数として読めないとき、
指数表記で書いたとき、同じ項目の単位の宣言が 2 行あるとき、入れ替え方の宣言が 2 通りある
とき、宣言された小数の桁に収まらない値を書いたとき(丸めて収める経路が無いため)。

## 使い方

```bash
python band_edge.py init ひな型/                           # 3 枚の表のひな型を書く
python band_edge.py check  値の表.csv 帯の表.csv 単位の宣言.csv   # 件数と分母の内訳
python band_edge.py match  値の表.csv 帯の表.csv 単位の宣言.csv   # 上 + 値ごとの内訳と指紋
python band_edge.py verify 値の表.csv 帯の表.csv 単位の宣言.csv   # 2 回 + 行順入れ替え + 覆い
```

終了コードは、**全ての行で帯が 1 つに決まったときだけ 0**、当たらない行や決まらない行がある
ときや止まったときは 3、表として読めなければ 2。まとめて走らせる仕組みの中に置いて、3 で
止められる。

関数としても同じ形で呼べる。

```python
from band_edge import Values, Bands, Units, match

m = match(Values.load("値の表.csv"), Bands.load("帯の表.csv"), Units.load("単位の宣言.csv"))
print(m.counts() if m.report.ok else [p.reason for p in m.report.pending])
```

CLI は `match` / `check` / `verify` / `init` の 4 つで、option は `-h` 以外に 1 つも無い。
そのこともテストで固定してある。

```bash
python -m pytest tools/band_edge -q      # 29 passed(2026-10-15 実走)
```

**値も帯の境目も対象も全て架空で、実在の金額や率や取引先名は 1 つも入れていない。** 帯で引く
軸の形(月額から段へ、日数から率へ)だけは、私の棚卸し記録(非公開)に出典つきで並んでいる
実在の軸を写した。**境界値そのものは写していない**(その記録自身が「値は未取得」「出典 URL
照合前」「条文照合は未実施」と書いているため)。出典のうち 4 件はこの repo 内の実在の行
(`articles/07_asof_table.md` L15 / `articles/08_formula_table.md` L14・L42 /
`articles/22_span_split.md` L16)を指し、テストがその行を開いて語が在ることまで確かめている。
`fixtures/make_fixtures.py` を実行すると、崩した表ごと書き直す。

## できないこと

- 判定したことは「宣言された帯と等号で、値の入る帯が 1 つに決まるか」までで、**どの等号が
  制度として正しいかは判定しない**
- **境界値がいくらかも言わない。** 値は入力の表から来るので、拾ってくるのは人の側になる
- **帯の一覧が足りているかも判定しない。** 書かれていない帯は無いものとして扱われるので、
  覆いの検算が見るのは「書かれた帯どうしの隙間」までになる
- **足すべき等号も境界値も提案しない。** 空欄の等号は止まるだけで、埋める候補を出す経路が無い
- 丸めない。小数の桁に収まらない値は、丸めて収めずに「表として読めない」で返る
- 日付で帯の表の版を選ばない。改定をまたぐ表は、版ごとに別の帯の表として渡す
- 対象(`target`)は結果に添えるだけで、帯の選び分けには使わない。対象ごとに帯が違う表は、
  項目を分けて渡すことになる
- 上の件数は、合成した表に対する測定で、他の人の環境で同じ数字になるとは限らない
