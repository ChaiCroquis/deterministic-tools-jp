# excel_report — 差異一覧を色分け Excel で人に返す。色は値ではないので、理由の列を先に置いてから塗る

差異を色だけで示した Excel は、値だけを読む工程(CSV 化・別のブックへの書き写し・値の貼り付け)を
1 つ通ると意味が落ちる。この道具は判定結果を **理由コードという値** として表に持ち、色はその列から
決定論で決まる従属表示として静的に焼く。条件付き書式は使わない(開いた時に Excel が評価する形にすると、
出力ファイル単体では結果が確定しない)。書いたら読み戻して「セル座標 → 理由コード」と件数と塗りを
突き合わせ、合わなければ出力を消して止まる。依存は openpyxl だけ。

## 呼ぶ側が渡す 3 つ

| 渡すもの | 中身 | 部品の側の扱い |
|---|---|---|
| 値の表 | 列の順 + 各行の値(文字列のまま) | 型を推測しない。先頭ゼロも全角数字もそのまま置く |
| セルごとの判定 | 行番号 / 列名 / 理由コード | 判定はしない。受け取ったものを置くだけ |
| 理由コードの表 | 理由コード / 意味の 1 行説明 / 塗り(RRGGBB) | 語彙は呼ぶ側のもの。部品は業種も判定の意味も持たない |

表に無い理由コード、表に無い行・列、同じセルに 2 つの理由 — このどれかが来たら、色を決める前に止まる。

## 出力の 3 シート(順も固定)

| シート | 中身 |
|---|---|
| 明細 | 元の値をそのまま置き、右端に `理由コード` の列を併置する。理由のあるセルだけを静的に塗る |
| 凡例 | 理由コード / 意味の 1 行説明 / 塗りの hex / 見本。色だけで意味を運ばないための欄 |
| 判断待ち | 1 セル 1 行で シート / セル座標 / 行番号 / 列名 / 値 / 理由コード。座標 → 理由の対応はここが正本 |

## 書いたあとの突合(合わなければ出力を消す)

- 見出しの並びと件数
- 全セルの値と、行ごとの `理由コード` 列の中身
- 「セル座標 → 理由コード」の対応(読むのは判断待ちシートの文字だけで、塗りは見ない)
- 理由コードごとの件数
- 塗り(セルに焼かれた色が「理由コード → 塗り」の表と一致するか)
- 凡例シートの行

差が 1 つでもあれば作業ファイルを消し、差の一覧(シート名 / セル座標 / 何の差 / 入力 / 読み戻し)を返す。
**色から理由を逆算する経路は作らない**(塗りを引数にして理由を返す関数も、色をキーにした表も持たない。
`tests/test_excel_report.py` が機械で確かめている)。

## いつも成り立つこと

書き出しの結果は 2 通りしかない。**値だけを読み戻しても(色を見なくても)、全セルの値と、判定したセルごとの理由コードが入力のとおりに読み取れ、塗られているのは判定したセルだけで塗りは理由コードの表のとおり、というファイルができる**か、**ファイルはできず、止まった理由(受け取ったものの食い違い、または読み戻しの差)が返る**か。表に無い理由コード・行・列や、同じセルへの 2 つ目の理由、xlsx に書けない文字(タブ・改行・CR 以外の制御文字、U+FFFE、U+FFFF)を含む見出し・値・理由コードを渡すと、色を決める前に止まる(後者になる。置換して書き進めない)。どちらの場合も作業ファイル(`.tmp.xlsx`)は残らない。

この 1 文は `tests/test_excel_report_property.py` が性質テスト(hypothesis)で確かめている。書ける値(日本語・先頭ゼロの数字・全角数字・空)と噛み合った判定だけの入力を乱数で作り、半分の確率で値を 1 か所だけ困る値(`=` で始まる文字列、`#N/A`、前後の空白、改行・CR・タブ、32,768 字の長い文字列、何でもありの文字列)に、半分の確率で判定を 1 件だけ困る形(表に無い行・列・理由コード、同じセルに 2 つ目、値の表に `理由コード` 列)にして、毎回この 1 文が成り立つかを見る(乱数は固定で、毎回同じ 200 通り)。読み戻しは道具の `verify` / `read_values` / `recover_reasons` / `read_fills` を使わず、テストの中で openpyxl を直接開いて読み、期待するセル座標と塗りもテストの中で別に作る。XML に書けない文字を含む値も困る値に入れて、書く前に止まり作業ファイルが残らないことを見ている。テストの実行には pytest と hypothesis が要る。

## 使い方

```
python excel_report.py 値の表.csv 出力.xlsx --judgments 判定.csv --reasons 理由コードの表.csv
python excel_report.py 値の表.csv --judgments 判定.csv --reasons 理由コードの表.csv --check   # 受け取ったものを見るだけ
python excel_report.py 値の表.csv 色だけ.xlsx --judgments 判定.csv --reasons 理由コードの表.csv --naive   # 比較用
# exit 0 = 書けた / 3 = 突合に差があり書かなかった / 2 = 受け取ったものが噛み合わない
```

```python
from excel_report import Table, ReasonTable, Judgment, write, recover_reasons, where_it_lives

table = Table.from_csv("sai_ichiran.csv")
reasons = ReasonTable.from_csv("riyu_hyou.csv")
judgments = [Judgment(3, "氏名", "値が無い")]          # 上流の部品が返したもの

r = write("sai.xlsx", table, reasons, judgments)
if not r.ok:
    for d in r.diffs:
        print(d.sheet, d.cell, d.what, d.original, d.readback)   # この時点で出力ファイルは無い
else:
    print(r.rows, r.pending, r.by_reason)

recover_reasons("sai.xlsx")                 # {'B4': '値が無い'} … 文字だけから復元する
where_it_lives("sai.xlsx", "値が無い")       # 理由コードが入っている zip の部品(シートの XML)
where_it_lives("sai.xlsx", "FFF1E8")        # 塗りが入っている zip の部品(styles.xml と凡例シート)
```

比較用に 2 つの書き出しも入れてある。`naive_write` は差異を色だけで示す書き出し(理由コードの列も凡例も
判断待ちシートも持たない)、`conditional_write` は塗りを条件付き書式で指定する書き出し(理由コードの列は
置くが、塗りはファイルの中で確定しない)。どちらも `verify` に通すと落ちる。

## テスト

```
pip install -r tools/excel_report/requirements.txt pytest   # openpyxl を記事で確かめた版(3.1.5)で入れる
python -m pytest tools/excel_report -q      # fixture は全て合成データ(fixtures/make_fixtures.py で再生成可)
```

`tests/test_excel_report.py` の `test_measure_*` が、合成 1,000 行の差異一覧(固定 seed)で
「色だけで示した出力」「条件付き書式で塗った出力」「この道具」を比べている。記事に載せる数値はそこから
取り、`assert 変数 == 値` で固定してある。読み戻しの一部は stdlib の zipfile でも見る
(openpyxl で書いたものを openpyxl だけで確かめる形を避けるため)。

## できないこと

- Excel 本体で開いた時の見え方は確かめていない。読み戻しは openpyxl と zipfile が読んだ値の話で、
  Excel が同じように描くかは見ていない
- 色の落ち方を試したのは「値だけを読む工程」(CSV 化 / 別のブックへ値で書き写す / 値の貼り付け)まで。
  Excel 本体の並べ替えでは塗りはセルと一緒に動くので、そこでは落ちない
- 淡色を 2 つの理由コードに割り当てても止めない。色の見分けやすさは機械では決められないので、凡例が正本
- 判定はしない。どのセルが判断待ちかを決めるのは呼ぶ側で、この道具は置き場所と突合だけを引き受ける
- 差の原因は推定しない。入力と読み戻しのどちらが正しいかも決めない
- 依存は openpyxl 1 つで、この環境の 3.1.5 でしか実行していない。文字を共有文字列表ではなくシートの
  XML に直接書くのはこの版の挙動なので、版が変われば `where_it_lives` の結果も変わる
- 1 つのセルに理由を 2 つ付けることはできない(どちらを塗るかが機械では決まらないので止まる)
- シート名・列名は固定(明細 / 凡例 / 判断待ち / 理由コード)。値の表に `理由コード` 列があると止まる
