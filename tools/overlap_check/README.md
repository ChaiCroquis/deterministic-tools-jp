# overlap_check — 今年の表の変更前の欄は去年の表と重なるので、検算に使うか収録に使うかを行ごとに書く

解説記事: [今年の表の変更前の欄は去年の表と重なるので、検算に使うか収録に使うかを行ごとに書く](https://chronicles-of-solo-parenting.blogspot.com/2026/10/blog-post_25.html)(2026-10-26 公開)

**公的な数表の資料は「変更前」と「変更後」を並べて出すので、同じ数字が 2 枚の資料に現れる。
その重なりは「突き合わせて検算にする」ことにも「片方しか資料が無い年を埋めて収録を 1 年
伸ばす」ことにも使えるが、同じ欄を両方の役に使うと一致件数が何を語っているか分からなくなる。**

[cross_route](../cross_route) の回は、同じ時点の値を 2 系統で取って「同じものを指しているか」を
先に疑う道具だった。あちらの重なりは**空間の方向**(別の配布元)で、こちらの重なりは**時間の
方向**(同じ発行元の別の年度)にある。[answer_check](../answer_check) は渡した行と返ってきた文章を
突き合わせる回で、相手が AI の答えだ。[cover_stock](../cover_stock) は年ごとに行がそろうかの在庫で、
そろっている年の行が 2 枚で突き合わされたかは数えない。

この部品は、年度ごとの抽出表・名前の寄せ方の表・行ごとの採用元の宣言・問いの一覧の 4 枚から、
問い 1 件ごとに 7 値(**一致 / 不一致 / 重なりが無い / 寄せ方が無い / 採用元が同じ欄** の 5 値 +
別枠 **単位がそろわない / 資料が手元に無い**)を付ける。不一致の組は両側の値と出典を並べ、
「採用元が同じ欄」だけの一覧も別に返す。**値を計算しない。どちらの年度を正とも決めない。
原文を取りに行かない。数えるだけだ。**

持たせていないものが規律になっている。

- **項目名を自動で寄せない**(寄せ方の表に無い項目名は比べずに「寄せ方が無い」に出す。**同じ
  文字列でも寄せたことを宣言させる**ので、表記ゆれをこの部品が判断する経路が無い)
- **採用元と同じ欄との比較を突合に数えない**(行の値を採った欄が、突き合わせに使う今年の
  変更前の欄そのものなら「採用元が同じ欄」に分ける。自分自身との一致を件数に混ぜる経路が無い)
- **どちらの年度を正とも決めない**(不一致は両方の値と両方の出典を並べて返すだけ。正を選ぶ
  引数も、優先順位の欄も無い)
- **不一致を直さない・片方だけの項目を新設とも廃止とも取り逃しとも決めつけない**(「重なりが
  無い」の 1 値にまとめ、理由は読む人に戻す)
- **資料そのものが手元に無い年度は別枠**(重なり候補の分母から外し、外した件数と年度を出す。
  行がそろうかを見るのは [cover_stock](../cover_stock) の仕事で、ここに寄せない)
- **値を計算しない・式を評価しない・丸め直さない**(文字列として取った値をそのまま比べ、単位の
  宣言がそろわない組は別枠。式は [formula_table](../formula_table)、丸めの前後は
  [compare_pick](../compare_pick) と役割を分ける)
- **一致率を割合にしない**(件数と 3 つの分母の内訳だけを返す)
- **出典の欄が空の行は使わずに止まる**
- **原文を取りに行かない**(ネットワークに触る経路が無い。入力は手元の抽出表だけ)
- **同じ年度どうしを突き合わせる指定を受け付けない**(その問いだけ止まる。同じ資料の 2 欄は
  年度をまたぐ重なりではない)
- **この部品自身の「読めない」を、測っている相手の「重なりが無い」と同じ欄に入れない**(4 枚の
  どれかが 1 行でも壊れていたら 1 件も数えず、理由コードだけを返す。7 値は全て 0 になる)
- **入力表を書き換えず、行も項目も生成しない**
- **同じ入力には同じバイト列**(判定部分に時刻・絶対パス・ホスト名を入れない。行順にも依らない)
- **数は整数だけ**

## 入力 — 4 枚の表

年度ごとの抽出表は 7 列。**1 つの資料の 1 つの欄の 1 項目が 1 行**。

| 列 | 意味 |
|---|---|
| `doc_id` | 資料 id(空欄・区切り文字入りは「表として読めない」) |
| `year` | 年度(1 つの年度に 2 つの資料 id は置けない。同上) |
| `item` | 項目名(資料に書かれたまま。寄せない) |
| `role` | 欄の役(`変更前` / `変更後`。登録外は「表として読めない」) |
| `unit` | 単位・桁の宣言。空欄はその組を別枠「単位がそろわない」へ |
| `value` | 値(文字列としてそのまま比べる)。空欄は**止まる** |
| `source` | 出典(空欄は**止まる**) |

同じ `doc_id` と `role` と `item` の組が 2 行あると**止まる**(同じ欄を 2 通り宣言している)。

名前の寄せ方の表は 4 列。**1 つの寄せが 1 行**で、ここに書かれた組だけが比べられる。

| 列 | 意味 |
|---|---|
| `item_a` | 年度 A(去年)の項目名。同じ項目名が 2 行あると**止まる** |
| `item_b` | 年度 B(今年)の項目名(同じ文字列でもここに書く) |
| `reason` | 寄せてよい理由(空欄は**止まる**) |
| `source` | 出典(空欄は**止まる**) |

採用元の宣言は 5 列。**収録した行 1 件が 1 行**。

| 列 | 意味 |
|---|---|
| `row_id` | 行 id(空欄・区切り文字入り・重複は「表として読めない」) |
| `item` | 項目名(年度 A の名前)。同じ項目名が 2 行あると**止まる** |
| `doc_id` | どの資料から採ったか(抽出表に無い id は**止まる**) |
| `role` | どちらの欄から採ったか(登録の 2 つ以外は**止まる**) |
| `source` | 出典(空欄は**止まる**) |

問いの一覧は 5 列。**1 つの突き合わせが 1 行**。

| 列 | 意味 |
|---|---|
| `year_a` | 去年の年度(この資料の「変更後」欄が経路 A) |
| `year_b` | 今年の年度(この資料の「変更前」欄が経路 B)。`year_a` と同じならその問いは**止まる** |
| `item` | 対象の項目名(年度 A の名前)。宣言が無ければ採用元の側で**止まる** |
| `source` | 出典(空欄は**止まる**) |
| `swap` | 入れ替え方(`逆順` / `両端入れ替え` / `1 つずらす`)。`verify` が 4 枚の行順を入れ替えるときの宣言 |

## 分け方 — 問い 1 件に付く 7 値

| 問いの形 | どうするか | 7 値 |
|---|---|---|
| 去年と今年が同じ年度 | 年度をまたぐ重なりではないので止まる | (止まった) |
| どちらかの年度の資料が手元に無い | 分母から外す | 資料が手元に無い |
| 寄せ方の宣言が無い項目 | 比べに行かない | 寄せ方が無い |
| 片側の欄が無い | 新設とも取り逃しとも決めつけない | 重なりが無い |
| 単位の宣言が空、または両側で違う | 比べられないので別枠 | 単位がそろわない |
| 行の値を採った欄が経路 B そのもの | 自分自身との比較なので分ける | 採用元が同じ欄 |
| 両側の値を文字列として比べた | 件数にする | 一致 / 不一致 |

上から順に見るので、**「寄せ方が無い」と「重なりが無い」は別の値になる**。名前の寄せ方を
宣言しないと、この 2 つは同じ塊に落ちる(名前が合わなかったのか、相手が無いのかが分からない)。

## 件数の検算 — 3 通りの数え方が合う

- **7 値の件数の合計 + 止まった問い = 問いの数**
- **5 値 + 単位がそろわない = 重なり候補の数**(資料が手元に無い問いは分母の外)
- **年度ペアごとの内訳の合計 = 問いの数**(問い 1 件はちょうど 1 つのペアに入る)

3 つは別の経路で数えているので、片方だけ数え方を差し替えるとこの検算が自分で見つけて止まる。
分母は 問いの数 / 重なり候補の数 / 別枠の数 の 3 つを必ず付ける。

## いつも成り立つこと

読んだ範囲は 2 通りしかない。

- 問い 1 件ごとに、7 値のどれか 1 つが付くか、同じ年度の指定で止まるかのどちらかで、**7 値の
  合計 + 止まった問いが問いの数**に等しく、**5 値 + 単位がそろわないが重なり候補の数**に等しく、
  **年度ペアごとの内訳の合計も問いの数**に等しく、**寄せ方の宣言が無い項目は両側の欄を持たない
  まま「寄せ方が無い」に出て**(同じ文字列でも自動で寄せない)、**採用元が経路 B の欄そのものの
  問いは一致にも不一致にも入らず**、**資料が手元に無い年度の問いは重なり候補の分母に入らず**、
  判定部分に時刻・ホスト名・絶対パスが 1 つも入らず、**4 枚の行順を入れ替えても同じバイト列**に
  なる
- または、1 件も数えずに理由コードが返る(数えた問いや指紋を取りに行くと例外になる)

どちらの場合も、この部品は 4 枚の表を 1 文字も書き換えない。

この 1 文を `tests/test_overlap_check_property.py` の `@given` テストが確かめている(資料を
2〜3 枚、項目を 1〜3 個、問いを 1〜3 件引き、各資料の変更前 / 変更後に項目を入れるかを引く。
単位は 円 / 日 / 空欄から、値は 2 通りから引くので一致・不一致・単位がそろわないが混ざり、
問いの年度には資料の無い `T0` も混ざる。3 割くらいの確率でどこか 1 か所を崩す。乱数は固定で
毎回同じ 200 通り)。**7 値の分け方はテストの側で別に実装している**(部品の `judge` / `seven` を
呼ばない)。同じファイルの 2 本目は「採用元が経路 B の欄そのものなら、両側の値が同じでも一致に
入れない」ことを見ている(組み合わせは 16 通りしかないので、上限 300 の下で全部を尽くす)。

## 出力 — 一致率は返らない

`check` と `overlap` が返るのは、4 枚それぞれの行数、3 つの分母、7 値の件数、突き合わせが成立
した件数、年度ペアごとの内訳、分母から外した年度、理由別の止まった件数、分母の内訳と検算、
それに 7 つの固定行だ。**割合だけを返す呼び方も、option も無い。**

```
"分母(問いの数)": 17,
"分母(重なり候補の数)": 15,
"分母(別枠の数)": 3,
"7 値": {"一致": 6, "不一致": 2, "重なりが無い": 2, "寄せ方が無い": 1,
         "採用元が同じ欄": 2, "単位がそろわない": 2, "資料が手元に無い": 1},
"突き合わせが成立した件数": 8,
"分母から外した年度": ["T0"],
"理由別の止まった件数": {"同じ年度を突き合わせる指定": 1},
"件数の合計の検算": "7 値の合計 16 + 止まった 1 / 問いの数 17(5 値 13 + …",
"項目名を自動で寄せない": "…",
"採用元と同じ欄を突合に数えない": "…",
"どちらの年度を正とも決めない": "…",
"片側しか無い項目を決めつけない": "…",
"一致率を割合にしない": "…",
"値を計算しない・原文を取りに行かない": "…",
"入力を書き換えない": "…"
```

`overlap` にすると、判定ごとの一覧、**不一致の組**(両側の資料 id / 値 / 単位 / 出典)、
**採用元が同じ欄だけの一覧**(行 id / 採用元 / 経路 B の欄 / 出典)、**重なりが無い組**、
止まった問いが出る。**名前は宣言に書かれたものがそのまま出る**(部品が書き足すことはしない)。

## 止まる理由コード(13 個)

4 枚の表の側。1 件も数えずに止まるものが 9 個。

`出典の欄が空` / `値の欄が空` / `同じ資料 id と欄の役と項目名の組が 2 行ある` /
`寄せてよい理由が空` / `同じ年度 A の項目名が 2 行ある` /
`採用元の欄の役が登録の 2 つでない` / `採用元の資料 id が抽出表に無い` /
`同じ項目名の採用元が 2 行ある` / `採用元の宣言が無い`

問い 1 件の側。その問いだけ止まるものが 1 個。

`同じ年度を突き合わせる指定`

`verify` が見つけるものが 3 個。

`件数の合計が合わない` / `2 回目の判定部分が不一致` / `行順を入れ替えた表で出力が変わる`

列が足りない・行が無い・id が空欄や区切り文字入り・同じ行 id や同じ問いが 2 行・欄の役が登録外・
1 つの資料に 2 つの年度・1 つの年度に 2 つの資料・登録外の入れ替え方、は**「表として読めない」**
(終了コード 2)で、理由コードには混ぜない。

## 使い方

```
python overlap_check.py init ひな型/
python overlap_check.py check   抽出表.csv 名前の寄せ方.csv 採用元の宣言.csv 問いの一覧.csv
python overlap_check.py overlap 抽出表.csv 名前の寄せ方.csv 採用元の宣言.csv 問いの一覧.csv
python overlap_check.py verify  抽出表.csv 名前の寄せ方.csv 採用元の宣言.csv 問いの一覧.csv
```

`verify` は 5 つ見る。2 回読んで判定部分のバイト列の指紋が同じか、宣言された入れ替え方で 4 枚の
行順を入れ替えても同じ出力になるか、件数の合計が 3 通りとも合うか、そして 2 つの写しだ。
**行 1 件の採用元を「今年の変更前」から「去年の変更後」に替えた写し**では、採用元が同じ欄が
1 減って一致が 1 増えること(件数が 1 対 1 で移ること)を見る。**寄せ方の表から 1 組外した写し**
では、寄せ方が無いが 1 増えた分だけ一致が 1 減り、ほかの年度ペアの件数が動かないことを見る。
写しはメモリの中だけで、入力の表には 1 文字も書かない。

終了コードは、別枠と止まった問いが 0 件のときだけ 0、在れば 3、表として読めなければ 2。
**どちらの年度が正しいかは、この終了コードにも出力にも出さない。**

関数でも呼べる。

```python
import overlap_check as H

t = H.overlap_check(H.Extracts.load("抽出表.csv"), H.Bridges.load("名前の寄せ方.csv"),
                    H.Takes.load("採用元の宣言.csv"), H.Questions.load("問いの一覧.csv"))
if t.report.ok:
    print(t.counts()["7 値"], t.self_checks())
```


`fixtures/` に入っているのは合成した 4 枚(抽出表 32 行 / 寄せ方 10 組 / 採用元 11 行 /
問い 17 件)と、理由コードを出すために 1 か所だけ崩した表 37 枚だ。**実在の料率・金額・取引先名
は 1 つも入っていない。** 資料 id も年度も項目名も値も架空で、値は `v11` のような記号にしてある。

## できないこと

- 判定したことは「文字列として同じか」までで、**どちらの年度が正しいかは判定しない**。不一致の
  組は両側の値と出典を並べるだけで、直す経路も無い
- **片方の年度にしか無い項目を、新設とも廃止とも取り逃しとも言わない。** 「重なりが無い」に
  まとめるので、理由は読む人が原文で確かめることになる
- **何割が一致したかを出さない。** 言えるのは件数と 3 つの分母までで、割合を返す経路が無い
- **2 経路は独立ではない。** 同じ発行元の別の年度の資料なので、見えるのは転記・抽出の壊れと
  年度をまたいだ不整合までで、発行元自身の誤りは 2 枚とも同じなら捕まらない
- **表記ゆれを寄せてはくれない。** 寄せ方の宣言は人が書く(同じ文字列でも書く)
- **年ごとに行がそろうかは見ない**([cover_stock](../cover_stock) の仕事)
- 上の件数は、合成した 4 枚の表に対する測定で、他の人の環境で同じ数字になるとは限らない
