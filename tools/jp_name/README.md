# jp_name — 氏名を決定論で寄せて照合キーを作り、同一人物かどうかの判断は人に返す

氏名の突合を「似ているから同じ人」で自動的に寄せると、間違いが静かに混ざる。
この道具は機械にできるところ(表記を決定論で寄せてキーを作る)までを引き受け、そこから先
(このキーの一致が同一人物を意味するか)は理由コードを付けて人に返す。
**類似度のしきい値を一切持たない。** stdlib のみ(unicodedata / re)、依存なし。

## 流れ(固定)

| 段 | すること | 判断待ちに落ちる条件 |
|---|---|---|
| 1 | 表記の正規化(NFKC で全角 → 半角・半角カナ → 全角カナ、空白と区切りを除く) | 空の氏名(記号だけ) |
| 2 | 異体字の同値化(`VARIANT_GROUPS` で代表字に畳む)/ ひらがな → カタカナ | 対象外表記(旧姓・通称の併記、3 語以上) |
| 3 | 相手側の索引を引く | 相手なし / 相手が複数 |
| 4 | 自分側の索引も引く | 自分側が重複(同姓同名。キーが人を一意に指さない) |

判断待ちの理由コードは 5 つ(`REASONS`)。どれも「機械では決まらない理由」を名前にしてある。

## 同値表(`VARIANT_GROUPS`)

各組の先頭が代表字。畳んでよいと決めた組だけを並べてある。

```
辺 邊 邉 / 斉 齊 / 斎 齋 / 高 髙 / 崎 﨑 / 沢 澤 / 浜 濱 濵 / 島 嶋 嶌 / 吉 𠮷 / 富 冨 /
徳 德 / 国 國 / 広 廣 / 郎 郞 / 竜 龍 / 真 眞 / 恵 惠 / 瀬 瀨 / 柳 栁 / 桧 檜 / 亀 龜 / 増 增
```

表に **無い** 組は別のキーになる。たとえば 斉 と 斎 は別の字なので `斉藤` と `斎藤` は畳まない
(`test_sai_groups_are_not_merged_on_purpose` で固定してある)。`井ノ口` と `井之口` も畳まない。
表を増やすこと自体が判断なので、増やすときはテストを足す。

漢字と読み(カナ)も畳まない。読みを持っていないので、同じ人かどうかを決められないため。

## 使い方

```
python jp_name.py --key 渡邊太郎 ﾜﾀﾅﾍﾞ ﾊﾅｺ      # 表記 TAB 照合キー
python jp_name.py A.csv B.csv --column 氏名     # A の各行を B に当てる。判断待ちが 1 件でもあれば exit 3
```

```python
from jp_name import to_key, build_index, match, match_all

to_key("渡邊 太郎")          # '渡辺太郎'
to_key("ﾜﾀﾅﾍﾞ ﾊﾅｺ")         # 'ワタナベハナコ'

d = match("渡辺 太郎", build_index(["渡邊太郎", "佐藤 花子"]))
d.status, d.candidates       # ('照合', ('渡邊太郎',))

for d in match_all(左の名簿, 右の名簿):
    if d.status == "判断待ち":
        print(d.name, d.reason, d.note, d.candidates)   # 人が見る行だけが残る
```

出力は「照合」か「判断待ち + 理由コード + 候補」のどちらかで、確率やスコアは返さない。

## テスト

```
python -m pytest tools/jp_name -q      # fixture は全て合成データ(fixtures/make_fixtures.py で再生成可)
```

`tests/test_jp_name.py` の `test_measure_*` が、合成 1,000 人の名簿 2 つで
「完全一致だけの突合」「類似度 0.8 以上を自動採用する突合」「この道具」を比べている。
記事に載せる数値はそこから取り、`assert 変数 == 値` で固定してある。

## できないこと

- 同一人物かどうかは決めない。決めるのは「照合キーが一致するか」だけ。判断待ちの行を人が見る前提の部品
- 読み(ふりがな)を持っていないので、漢字表記とカナ表記は結び付かない。読みの列があるなら、そちらを別のキーとして併用する
- 旧姓・通称・ミドルネームは対象外表記として判断待ちに落とす。どちらが現姓かは名簿の外の情報で、機械では決まらない
- 同値表は 22 組しか持っていない。手元の名簿に出る異体字は足りなければ足す(足すこと自体が判断)
- 島 と 嶋、浜 と 濱 を畳むのは、この表が置いている判断。別の家として扱いたい名簿では組を外す
- ローマ字表記の大文字小文字は畳まない。姓名の順序も判定しない
- 敬称(様 / 殿 / さん)や役職の付いた列は、先に切り落としてから通す
