# asof_reach — 公表時点の欄が埋まっていても当時の知識とは限らないので、仮置きの種類と再現が届く範囲を行ごとに分ける

公表時点を列に持てば「当時の知識」を再現できる、と宣言した表でも、**その列が実値で埋まっている行はごく一部で、残りは施行日をそのまま写した仮置き**のことがある。しかも仮置きには種類があり、施行日で埋めた行・確認済の範囲の先頭で埋めた行・公布日で埋めた行で、`as_of` を戻したときの振る舞いが別々になる。

この部品は、4 枚の台帳から行 1 件ごとに 4 値 + 別枠を付け、問い 1 件ごとに「その `as_of` で答えが返るか」を 3 値で返す。**公表日を取りに行かない。仮置きが誤りだと決めない。再現できる率の 1 値を返さない。走らせない。**

```
python asof_reach.py check 行.csv 品質.csv 問い.csv 宣言.csv
```

## 持たせていないもの

- **公表日を推定しない**。暦・版の名前・日付の形から品質の種類を当てる経路が無い。品質の記号は登録表に在るものだけを使い、無い記号は別枠へ出す
- **取りに行かない**。外へ取りに行かない・走らせない・実行しない・import しない・構文解析しない・通信の経路が無い・入力フォルダの外を読まない
- **仮置きを実値へ格上げしない**。品質の記号を書き換える経路が無い。別出典の公表日の欄が埋まっていても、記号が仮置きなら仮置きのまま数える
- **正しい側を決めない**。仮置きが誤りだと言う列も、直すべき順位の列も、点数の列も無い。4 値は状態の名前で、良し悪しの順ではない
- **再現できる率を単独で返さない**。率の 1 値を出す列が無く、件数には必ず分母が並ぶ(**行の側と問いの側で分母が別**)
- **理由を言い当てない**。理由の欄は注記の写しだけで、空なら `理由の記載なし` を入れる。なぜ仮置きにしたかを当てる辞書も分類器も持たない
- **宣言の文を採点しない**。宣言の台帳の文と、その文が主張する範囲と、観測の側の件数を並べるだけ
- **時計を読まない**(`as_of` と基準日は問いの台帳から来る = 呼ぶ側が渡す)。**入力を書き換えない**。**float を使わない**(日数と件数は整数、ほかは文字列)

## 入力 — 4 枚

**どの行にも出典(ファイル名 + 行番号)の欄が要る。** 登録表の行に出典が無ければ、1 行も数えずに止まる。

### 行の台帳(10 列)

| 列 | 中身 |
|---|---|
| `row_id` | 行 id(同じ id が 2 行あると止まる) |
| `value_name` | 求める値の名前(**判定には使わない**。この文字から品質を推測する経路が無い) |
| `valid_from` | 効き始める日(ISO の日付。`開` にも記載なしにもできない) |
| `valid_to` | 効き終わる日(ISO の日付 / `開` = 開いている / `—` = 記載なし) |
| `known_from` | 公表時点の始まり(ISO の日付 / `—` = 記載なし → (D)) |
| `known_to` | 公表時点の終わり(ISO の日付 / `開` / `—` = 記載なし → (D)) |
| `announced` | 別出典の公表日(空可。品質が `実値` のとき空だと別枠へ) |
| `reason` | 理由の文字列(空可。**原文の写しだけ**。空なら `理由の記載なし`) |
| `grade` | 品質の記号(登録表に在る記号だけ。無ければ別枠へ) |
| `source` | 出典。空欄のとき、その行は別枠「出典が空」へ入る |

**`開` と記載なしを同じ値にしない。** 開いていると宣言された端は `開` と書き、書かれていない端は `—` のままにする。後者は知識時間の経路が無い行として (D) に入る。

### 品質の記号の登録表(4 列)

| 列 | 中身 |
|---|---|
| `grade` | 記号(同じ記号が 2 行あると読めない) |
| `means` | 意味(`実値` / `施行日で仮置き` / `範囲の先頭で仮置き` / `公布日で仮置き` / `不明`。ほかの語が在ると止まる) |
| `requires` | その記号が要求する欄(`別出典の公表日` / `理由の文字列` / `—`) |
| `source` | 出典。空欄のとき 1 行も数えずに止まる |

**この表だけが仮置きの種類を決める。** 日付の形を見て「これは施行日の写しだろう」と当てる経路は無い。`実値` は別出典の公表日を要求し、仮置き 3 種は理由の文字列を要求する(どちらが欠けても別枠へ出るが、**別枠の枠は 2 つに分かれている**)。

### 問いの台帳(5 列)

| 列 | 中身 |
|---|---|
| `ask_id` | 問い id(同じ id が 2 行あると読めない) |
| `row_id` | 行 id(行の台帳に無いと別枠 7 へ) |
| `as_of` | 渡す `as_of`(ISO の日付。空だと止まる) |
| `basis_date` | 渡す基準日(ISO の日付。空だと止まる) |
| `source` | 出典 |

**`as_of` と基準日はこの表から来る。** 部品は現在時刻を読む呼び出しを持たない。

### 宣言の台帳(4 列)

| 列 | 中身 |
|---|---|
| `claim_id` | 宣言 id(同じ id が 2 行あると読めない) |
| `text` | 再現できると書いた文の verbatim |
| `scope` | その文が主張する範囲(`全行` / `一部` / `記載なし`。ほかの語が在ると止まる) |
| `source` | 出典 |

**この文が正しいかを採点する経路は無い。** 文と範囲と、観測の側の件数を並べるだけになる。

## 分け方 — 行 1 件に付く 4 値と別枠 7

| 値 | 意味 |
|---|---|
| (A) | 品質が `実値` で、`known_from` と `valid_from` が別の日(公表の前と後が行で分かれ、`as_of` を公表日の前日へ戻すとその行は出ない) |
| (B) | `known_from` が `valid_from` と同じ日(`as_of` を戻すと行は消えるが、消えた理由が「まだ公表されていない」と「まだ効いていない」の 2 通りあり、どちらとも言えない = `見分け不能` の印が付く) |
| (C) | 境界日は別の日だが、品質が仮置き 3 種のどれか(日付が動いているので (A) と同じ形に見えるが実値ではない) |
| (D) | 知識時間の経路が無い(`known_from` が記載なし / `known_to` が記載なし / 品質が `不明`) |

別枠は上から順に当たり、**4 値より先に当たる**。

| 枠 | 分母 |
|---|---|
| 出典が空 | 行 |
| 品質の記号が登録表に無い | 行 |
| 記号が要求する欄が空(仮置きなのに理由の文字列が無い) | 行 |
| 公表が施行の後(遡及の形)なのに公表日が仮置き | 行 |
| 品質が `実値` なのに別出典の公表日が空 | 行 |
| `known_to` が閉じているのに同じ値の名前の後続行が台帳に無い | 行 |
| 問いの台帳が指す行 id が行の台帳に無い | **問い** |

**最後の 1 枠だけ分母が問いの側**なので、行の件数の合計には混ぜない(混ぜると合計が合わなくなる。これは数え間違いではなく、分母が 2 つあるという事実)。

## 問い 1 件に返る 3 値 — 再現が届く範囲

| 値 | いつ |
|---|---|
| `出る` | `as_of` が知識時間の中で、基準日が有効時間の中 |
| `出ない` | 知識時間の外で、その境界が実値の公表日(= 公表前だと言える)/ または有効時間の端が決めた |
| `言えない` | 知識時間の外だが、その境界が仮置きか同じ日の境界 / または知識時間の経路が無い |

答えには「答えが乗っているもの」が必ず付く(`実値の公表日` / `有効時間の端` / `同じ日の境界(見分け不能)` / `仮置きの公表日` / `知識時間の経路が無い` / `別枠`)。**どの境界が答えを決めたかを言わずに 3 値だけ返す経路は無い。**

## いつも成り立つこと

読んだ範囲は 2 通りしかない。

- **4 値を付けた**: **行 1 件ごとに 4 値か行に付く別枠 6 のどれか 1 つ**が付き、**その合計 = 行の件数**、**品質の意味ごとの内訳の合計も同じ数**になる。**品質が `実値` でない行は (A) に入らず**、**境界日が同じ日の行は (A) と (C) に入らず**、**知識時間の経路が無い行は (A)(B)(C) に入らず**、**`開` と記載なしを同じ値にせず**、**(B) にだけ `見分け不能` の印が付く**。2 通りの数え方の差は必ず「(C) の件数 − (B) のうち品質が `実値`」に等しい。**問いの分母は行とは別**で、行の台帳に無い行 id を指す問いは 3 値に入らない。判定部分に値の名前も理由の文字も絶対パスも入らず、**値の名前を全部入れ替えても、4 枚の行順を 3 通りに入れ替えても、同じバイト列**になる
- **1 行も数えずに理由コードが返る**: 4 値や sha256 を取りに行くと例外

どちらの場合も、この部品は 4 枚の表を 1 文字も書き換えない。

この 1 文を検査にしたのが `tests/test_asof_reach_property.py`(hypothesis、`derandomize=True`)。4 値の決め方はテストの中に別に書いてあり、部品の `judge` / `four` / `extras` を呼ばない。

## 件数の検算 — 2 通りの数え方と、その差

`check` の出力の `件数の合計の検算` が、同じ件数を別の切り口で数えて並べる。

- 4 値 + 行に付く別枠 6 の合計 = 行の件数
- 品質の意味(`実値` / 仮置き 3 種 / `不明` / 登録表の外)ごとの合計 = 行の件数
- **2 通りの数え方の差** = 境界日が別の日である件数 − 品質が `実値` の件数。これは必ず「(C) の件数 − (B) のうち品質が `実値`」に等しい

**分母は (A)(B)(C) = 知識時間の経路が在る行**で、(D) と別枠は入らない。率を出したい人は、行の件数で割るか、この分母で割るか、問いの件数で割るかを自分で選ぶことになる。**3 つは同じ数字にならない。**

## 止まる理由コード(8 個)

登録表の行の出典が空 / 行 id の重複 / 品質の登録表の意味が決めた 5 つの外 / 品質の登録表の要求する欄が決めた 3 つの外 / 日付の欄が ISO の日付でない / 宣言の台帳の範囲が決めた 3 つの外 / 問いの台帳の `as_of` か渡す基準日が空 / 登録表そのものが空。

**止まった表は 4 値を 1 件も返さない**(4 値も別枠も全て 0 で、理由コードだけが返る)。表として読めないとき(列が足りない / 行が無い / 行 id が空 / 期間の端が逆 / 品質の登録が同じ記号で 2 行 / 問い id が 2 行 / 宣言 id が 2 行)は終了コード 2。

## 使い方

```
python asof_reach.py init ひな型/
python asof_reach.py check  行.csv 品質.csv 問い.csv 宣言.csv
python asof_reach.py report 行.csv 品質.csv 問い.csv 宣言.csv
python asof_reach.py verify 行.csv 品質.csv 問い.csv 宣言.csv
```

`report` は行ごとの一覧と問いごとの一覧、品質の意味ごとの内訳、宣言の台帳、判定部分の sha256 を足す。`verify` は 5 つ見る。

- 2 回読んで判定部分の指紋が同じか
- 4 枚の行順を 3 通りに入れ替えても同じか
- 4 値 + 別枠 6 の合計が行の件数に戻り、品質の意味ごとの合計も同じで、2 通りの数え方の差が検算の形に合うか
- 1 行の `known_from` を `valid_from` と同じ日に書き換えると、**その行だけ**が (A) → (B) へ移り、差が 1 減るか
- 1 行の品質の記号を `実値` から `公布日で仮置き` に替えると、**その行だけ**が (A) → (C) へ移り、差が 1 増えるか

終了コードは、止まらず・別枠 0 件・(B)(C)(D) が 0 件のときだけ 0、在れば 3、表として読めなければ 2。

## テストと fixture

```
python -m pytest tools/asof_reach -q
```

`fixtures/` の 4 枚は合成で、**実データ・実在の名前・実在のパスは 1 つも入っていない**(行 id は記号、値の名前は「合成の値 …(架空)」、品質の記号は「記号 1〜5」、出典は「合成の…(架空)」)。日付も架空の暦の上の日付で、実在の改定日と一致させていない。`fixtures/kowashita/` に、止まる理由コード 8 個と表として読めない 7 通りへ道を付けた崩した表が入っている。`fixtures/make_fixtures.py` で作り直せる。

## できないこと

- **公表日が本当は何日かは分からない。** 取りに行く経路が無い。別出典の公表日の欄も、人が書いた文字をそのまま使う
- **仮置きが誤りかは分からない。** 4 値は状態の名前で、良し悪しの順ではない。(C) でも「直すべき」とは言っていない
- **なぜ仮置きにしたかは分からない。** 理由の欄は写しだけで、書かれていない行は `理由の記載なし` になる
- **再現できる割合は返さない。** 分母が 3 通り(行の件数 / 知識時間の経路が在る行 / 問いの件数)あり、どれで割るかは読む人が決める
- **宣言の文が正しいかは分からない。** 文と範囲と件数を並べるだけで、突き合わせの判断は人に残る
- **`言えない` が返った問いの本当の答えは分からない。** 言えないことを言えないまま返すのが、この部品の返り値になる
- 上の件数は合成した 4 枚に対する測定で、ほかの人の環境で同じ数字になるとは限らない
