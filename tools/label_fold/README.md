# label_fold — 項目名の対を畳む手順に通し、同じになる対とならない対を分けて並べる

2 つの文書で同じ項目を指す名前は、全角と半角・空白・記号を揃えれば同じ字になるものと、略した呼び方のように揃えても同じ字にならないものが混ざる。
この部品は、**人が書いた 3 表**を読み、登録された対を登録された手順に 1 段ずつ通して、どの段で同じ字になったか、最後まで同じにならなかったかを並べるところで止まる。
**似ている度合いを出さない。対を作らない。略語を補わない。** 標準ライブラリのみ、依存なし。

## 入力(3 表、UTF-8 の CSV)

| 表 | 列 |
|---|---|
| 名前の台帳 | 名前id / 文書id / 名前 / 切り方のメモ / 出典 |
| 畳む手順の登録表 | 順番 / 手順の種類 / 除く記号 / 出典 |
| 対の登録表 | 対id / 左の名前id / 右の名前id(片側は空でもよい)/ 読みのメモ / 出典 |

- 手順の種類は `NFKC` `空白を除く` `登録した記号を除く` `英字の大文字小文字を揃える` の 4 つだけ。`除く記号` は 3 つ目のときだけ書く
- 名前は書かれた字のまま比べる(前後の空白も落とさない)。ほかの列は前後の空白を落とす
- 出典はどの行にも要る

## 出力

| 区分 | 意味 |
|---|---|
| A | 書かれたまま同じ |
| B | 畳むと同じ(同じになった段の順番と種類が付く) |
| C | 全段を通しても違う(畳んだ後の両側の字をそのまま返す) |
| D | 相手なし |

補助の印は 2 つ。C の中で片側の畳んだ字がもう片側に丸ごと含まれる / 対に無いが畳むと同じ字になる名前の組。どちらも区分を動かさず、同じ項目だとも言わない。
記号や空白を除いて両側とも空になった対は、同じとせず C に置く。

別枠は 6 つ(区分に入れず理由を返す): 登録表に無い手順の種類 / 対が指す名前idが台帳に無い / 出典が空 / 同じ名前idが2回 / 同じ名前idが2つの対に出る / 対の両側が同じ文書id。
手順の行が別枠に出たときは、その手順を当てずに残りを通す(終了コードは 3)。

列が無い、順番が整数でない・重複、`除く記号` の有無が種類と合わない、名前が空、対id が空・重複のときは、1 対も並べずに止まる。

## いつも成り立つこと

対の登録表の 1 行は区分 A〜D か別枠のどれか 1 か所にだけ入り、**区分は、書かれた字と、登録した手順を順番どおりに当てた字が同じかどうかだけで決まる**(名前id の重複が無ければ、名前の台帳の行順を入れ替えても結果は同じ)。

この 1 文は `tests/test_label_fold_property.py` が性質テスト(hypothesis)で確かめている(乱数は固定で毎回同じ 300 通り)。畳み方と仕分けは道具の関数を使わず、テストの中で別に書いている。

## 使い方

```
python label_fold.py --names fixtures/shuuroku/names.csv --steps fixtures/shuuroku/steps.csv --pairs fixtures/shuuroku/pairs.csv --verify
```

`--json` で JSON。終了コードは 0 = 全ての対が A か B で、別枠も「対に無いが畳むと同じ組」も無い / 3 = 人が見る行がある / 2 = 表が読めない / 4 = `--verify` が合わない。

## テストと fixture

```
python -m pytest tools/label_fold -q      # 24 passed
python fixtures/make_fixtures.py          # fixture を作り直す
```

| 置き場 | 中身 |
|---|---|
| `fixtures/gousei/` | 合成(架空の備品の一覧)。対 13 行で、区分 4 つと手順 4 つに当たる |
| `fixtures/kowashita/` | 崩した表。別枠 6 つに 1 件以上ずつ当たる |
| `fixtures/shuuroku/` | 私の記録 2 文書の項目名から起こした登録表(対 18 行)。項目名だけで、率・金額・人の情報は無い |
| `fixtures/hojo_mijikai/` `fixtures/hojo_nagai/` | 補助。3 つ目の文書の項目名 5 つと、それぞれの文書の対 |

## できないこと

- どの名前とどの名前が同じ項目かは決めない(人の登録)。名前の切り方も人が決める
- C は誤記という意味ではない。B は同じ項目だという証拠ではない
- 同じになった段は手順の順番で動く
