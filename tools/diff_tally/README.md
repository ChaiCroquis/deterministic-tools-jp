# diff_tally — 差分の件数が 0 の回でも出力の指紋は変わるので、2 経路で並べてから書く

「表が変わったか」には独立な 2 経路の数がある。① 差分の記録に出る増えた / 減った / 中身が替わった行数、② 出力の指紋。**この 2 つは同じ回について別の答えを返すことがある。** 片方だけを見て「変わっていない」と書くと、もう片方が変わった回を取りこぼす。

この部品は、5 枚の表から、順序番号で隣り合う回の対ごとに 6 値のどれか 1 つを付け、併せて **戻りの印**(指紋が前の回ではなく過去のどれかの回と同じ文字列)を出す。さらに累積の突合を 1 行だけ返す。**どちらの経路が正しいかは決めない。**

```
python diff_tally.py check 実行の記録.csv 棚卸し.csv 欄.csv 結果記号.csv 差の理由.csv
```

## 持たせていないもの

- **出力に「正しい経路」「信頼できる方」「一致率」の欄が無い**。2 経路の値と、食い違っている形だけを並べる。どちらを直すかを決める引数も、並べ替える引数も無い
- **差の原因を推定しない**。理由は差の理由の宣言表の写しだけで、宣言が無ければ `宣言なし`。原因を当てる辞書も regex も持たない
- **単位と期間を入力に宣言させてから出す**。欄ごとの単位記号が登録の 2 つでなければ表として読めない。対象の期間は入力の順序番号の最小と最大をそのまま写す
- **ハッシュを計算しない**。指紋は入力の文字列を比べるだけで、file を読んで hash にする経路が無い(`hashlib` を呼ぶのは判定部分の sha256 の 1 か所だけ)
- **中身が替わった行数を累積に足す関数そのものを置かない**。累積に入るのは欄の登録表で `増やす` / `減らす` と宣言された欄だけで、`動かさない` と宣言された欄は入る経路が無い
- **指紋から行数を推測しない / 行数から指紋を作らない**
- **成功率を出さない**(落ちた回の仕分けは別の部品の領分)。**周期を読まない**。**検証の件数を分解しない**。**どの行を出し直すかを決めない**
- **差分の中身の値を読まない**(入るのは件数と記号と指紋の文字列と出典だけ)。**現在時刻を読まない**。**pipeline を走らせない**。**入力を書き換えない**。**float を使わない**

## 入力 — 5 枚

**どの行にも出典の欄が要る。** 空欄の行が 1 つでも在れば、1 対も数えずに止まる。

### 実行の記録の台帳(8 列)

1 回の実行が 1 行。**2 経路を同じ 1 行で持つ。**

| 列 | 中身 |
|---|---|
| `run_id` | 実行 id(同じ id が 2 行あると読めない) |
| `seq` | 順序番号(1 以上の整数。重複や飛びが在ると止まる) |
| `status` | 結果記号(登録表に無ければ止まる) |
| `added` | 増えた行数(0 以上の整数 または `記載なし`) |
| `removed` | 減った行数(同じ) |
| `changed` | 中身が替わった行数(同じ。**累積に足す経路が無い**) |
| `fingerprint` | 出力の指紋の文字列(または `記載なし`)。**長さが揃っていないと止まる** |
| `source` | 出典(ファイル名 + 行番号) |

```csv
run_id,seq,status,added,removed,changed,fingerprint,source
R01,1,S1,1301,0,0,sa010000000000000000,合成の実行履歴のメモ(架空)L1
R03,3,S2,記載なし,記載なし,記載なし,記載なし,合成の実行履歴のメモ(架空)L3
R10,10,S1,0,0,0,se0500000000000000000,合成の実行履歴のメモ(架空)L10
```

### 棚卸しの台帳(4 列)

| 列 | 中身 |
|---|---|
| `asof` | 時点記号(重複すると止まる) |
| `rows` | 宣言された行数(0 以上の整数) |
| `rules` | 宣言された rule 数(0 以上の整数) |
| `source` | 出典 |

**突合に使うのは時点記号の並びで最後の 1 行だけ**で、残りは「突合に使っていない棚卸しの時点」の一覧へ出す(黙って落とさない)。

### 欄の登録表(4 列)

**差分の 3 欄すべてを登録する**(1 つでも無いと止まる)。

| 列 | 中身 |
|---|---|
| `field` | 欄名(`added` / `removed` / `changed`) |
| `moves` | 行数を動かすか記号(`増やす` / `減らす` / `動かさない`) |
| `unit` | 単位記号(`行` / `回`)。**登録の外なら表として読めない** |
| `source` | 登録の出典 |

### 結果記号の登録表(4 列)

| 列 | 中身 |
|---|---|
| `status` | 結果記号 |
| `replaces` | 本番の出力を差し替えるか(`差し替える` / `差し替えない`) |
| `cumulative` | 累積に入れるか(`入れる` / `入れない`)。**累積の定義はここに在る** |
| `source` | 登録の出典 |

### 差の理由の宣言表(4 列、ヘッダだけでもよい)

| 列 | 中身 |
|---|---|
| `from_run` | 対の前の実行 id |
| `to_run` | 対の後の実行 id(**どちらも台帳に実在しないと止まる**) |
| `reason` | 理由コード(人が書いた宣言) |
| `source` | 出典 |

隣り合っていない対を指す宣言は、止めずに「どの対にも当たらない理由の宣言」の一覧へ出す。

## 分け方 — 回の対 1 つに付く 6 値

| 値 | 意味 |
|---|---|
| 差分が 0 で指紋も前の回と同じ | 2 経路が揃って「動いていない」 |
| 差分は 0 なのに指紋が前の回と違う | **2 経路が別の答え** |
| 差分は 0 でないのに指紋が前の回と同じ | **2 経路が別の答え** |
| 差分も指紋も動いた | 2 経路が揃って「動いた」 |
| 差分の欄が `記載なし` | 本番の出力を差し替えていない回の形 |
| 指紋が `記載なし` | 片方の経路の記録が無い |

上から順に見る。差分の欄に `記載なし` が在れば、そこで終わり(**指紋が在っても 0 と読まない**)。どちらかの指紋が `記載なし` でも終わり。そこから先で、はじめて差分の 3 欄が 0 かを見て、指紋の文字列を比べる。

併せて **戻りの印** = 指紋が前の回ではなく過去のどれかの回と同じ文字列(一致した run id をそのまま出す)。

## 中身が替わった行数が、累積と差分で別に働くこと

`changed` は差分の記録の側では「動いた」と言うのに、行の数は動かさない。だから 2 か所で別に働く。

- **6 値の側**: `changed` が 1 件でも在れば「差分が 0」ではない(→ ③ か ④ へ行く)
- **累積の側**: `動かさない` と宣言されているので、累積に入る経路が無い

合成の表では、累積(`added` の和 − `removed` の和)が 1,681 行で棚卸しの宣言 1,681 行と一致する。**`changed` の 3 件を足すと 1,684 になって合わなくなる。**

## いつも成り立つこと

読んだ範囲は 2 通りしかない。

- **対を作った**: 回の対 1 つごとに 6 値のどれか 1 つが付き、**6 値の合計 = 回の件数 − 1**、**結果記号ごとの内訳の合計 = 回の件数**。「差分が 0 で指紋も前の回と同じ」の対は差分の 3 欄が 0 かつ指紋が前の回と同一、「差分は 0 なのに指紋が前の回と違う」の対は差分の 3 欄が 0 かつ指紋が前の回と別、「差分は 0 でないのに指紋が前の回と同じ」の対はその逆。戻りの印が付く対は指紋が前の回と違い、かつ過去のどれかの回と同じ文字列。累積は `増やす` / `減らす` と宣言された欄だけで決まり、`動かさない` と宣言された欄を 1 件増やしても動かない。出力に「正しい経路」「一致率」の欄が無く、判定部分に絶対パスが入らず、5 枚の行順を 3 通りに入れ替えても同じバイト列になる
- **1 対も数えずに理由コードが返る**: 作った対や sha256 を取りに行くと例外

どちらの場合も、この部品は 5 枚の表を 1 文字も書き換えない。

この 1 文を検査にしたのが `tests/test_diff_tally_property.py`(hypothesis、`derandomize=True`)。読み戻しと分類はテストの中に別に書いてあり、部品の `judge` / `six` を呼ばない。

## 件数の検算 — 2 通りの数え方が合う

- 6 値の合計 = 回の対の件数(= 回の件数 − 1)
- 結果記号ごとの内訳の合計 = 回の件数

`verify` はこの 2 つに加えて、判定部分の sha256 の二度走り、5 枚の行順の 3 通りの入れ替え、そして 3 つの写しを見る。

- **指紋を前の回と同じにした写し**: ④ の対が ③ へ移り、**累積の突合の数は変わらない**(指紋と累積が別経路であることの物理形)
- **中身が替わった行数を 1 件増やした写し**: **累積の突合の差は変わらない**(足す経路が無いことの物理形)
- **累積の宣言を `入れない` から `入れる` に替えた写し**: **累積だけが動いて 6 値の区分は変わらない**(累積の定義が結果記号の登録表の側に在ることの物理形)

## 出力 — 正しい経路も一致率も返らない

`check` は件数と分母の内訳、`pairs` はそれに一覧を足す。返るのは次のものだけ。

- 5 枚の行数、分母(回の件数 / 回の対の件数)、対象の期間
- 6 値、2 経路が別の答えを返した対の件数、片方の欄が `記載なし` の対の件数、戻りの印の件数
- 結果記号ごとの回の数、2 経路の単位(欄ごとの単位記号と、指紋の `文字列の一致`)
- 累積の突合 1 行(累積 / 棚卸しの宣言 / `一致` か `差がある` / 差の値 / 単位 / 対象の期間)
- 突合に使っていない棚卸しの時点、どの対にも当たらない理由の宣言、理由別の止まった件数

`pairs` で足されるのは、判定ごとの一覧、2 経路が別の答えを返した対の一覧、片方の欄が `記載なし` の対の一覧、戻りの印の一覧、突合に使っていない棚卸しの時点の一覧、どの対にも当たらない理由の宣言の一覧、判定部分の sha256、読んだ条件。

**「正しい経路」「信頼できる方」「一致率」の欄は無い。** 出力の最後に並ぶ 14 行の「持たせていないもの」は消せない。

## 止まる理由コード(11 個)

表の側は 8 個。**どれか 1 つでも在れば、1 対も数えない**(6 値は全て 0)。

- 出典の欄が空
- 欄名が登録表に無い
- 結果記号が登録表に無い
- 順序番号の重複または飛び
- 件数が整数でない
- 指紋の文字列の長さが揃っていない
- 棚卸しの時点記号の重複
- 理由の宣言表が実在しない run id の対を指す

`verify` が見つけるのが 3 個 = 件数の合計が合わない / 2 回目の判定部分が不一致 / 行順を入れ替えた表で出力が変わる。

表として読めない形(列が無い / 行が無い / 順序番号が整数でない / 登録の外の記号 / 同じ id が 2 行)は終了コード 2 で、回の対は 1 つも数えない。

## 使い方

ひな型を出す。

```
python diff_tally.py init ひな型/
```

数える。

```
python diff_tally.py check 実行の記録の台帳.csv 棚卸しの台帳.csv 欄の登録表.csv 結果記号の登録表.csv 差の理由の宣言表.csv
```

一覧つきで出す。

```
python diff_tally.py pairs 実行の記録の台帳.csv 棚卸しの台帳.csv 欄の登録表.csv 結果記号の登録表.csv 差の理由の宣言表.csv
```

この手続き自体が決定論かを実測する。

```
python diff_tally.py verify 実行の記録の台帳.csv 棚卸しの台帳.csv 欄の登録表.csv 結果記号の登録表.csv 差の理由の宣言表.csv
```

終了コードは、2 経路が揃わない対(②③⑤⑥)と戻りの印と累積の差と止まった行が 0 件のときだけ 0、在れば 3、表として読めなければ 2。**0 は「変わっていない」ではなく「2 経路が全ての対で同じ答えを返した」の意味。**


## できないこと

- **どちらの経路が正しいかは分からない。** 2 経路が別の答えを返した対を並べるだけで、どちらを直すかは読む人が決める
- **差の原因は分からない。** 出るのは宣言表の写しだけで、宣言が無ければ `宣言なし`
- **指紋が何を含んでいるかは分からない。** 文字列の一致しか見ないので、出力の並べ方が変わっただけなのか中身が変わったのかは、この部品では区別できない
- **累積が正しいかは分からない。** 累積に入れるかの宣言は人が書くもので、この部品は宣言どおりに足し引きするだけ
- **実行の回が本当に全部記録されているかは分からない。** 順序番号の飛びは見るが、記録されなかった回は飛びとしても現れない
- **検証が通ったかは分からない。** 結果記号の意味づけは登録表の宣言で、この部品は走らせない
- 上の件数は合成した 5 枚の表に対する測定で、ほかの人の環境で同じ数字になるとは限らない
